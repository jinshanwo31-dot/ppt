# 交付说明与逐页核查

使用 ppt-master 6.7.3 制作。全新32页，1920×1080、16:9；总计120分钟，含第13页5分钟休息。按新逐页文案重建，未逐页替换旧38页。

## 使用前

1. 学校补齐第30和32页的“校内心理老师/地点/预约方式”占位。
2. 核对主讲人称谓、学校现场个别支持与转介流程。
3. PPTX使用 Noto Sans CJK SC 与 Noto Serif CJK SC。编辑电脑应安装这两款字体，避免自动替换导致排版改变；PDF已嵌入字体，适合直接投影或打印。
